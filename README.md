# Homebrew tap for NOIDA

[NOIDA](https://github.com/its-banana-coder/noida) is a terminal IDE built around Claude Code and Codex.

```bash
brew install its-banana-coder/noida/noida
```

Upgrade with `brew upgrade noida`. The formula is generated from each release by
[`scripts/update-homebrew.sh`](https://github.com/its-banana-coder/noida/blob/main/scripts/update-homebrew.sh); don't edit it by hand.
